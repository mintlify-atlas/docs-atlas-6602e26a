K64 is an experimental 64-bit x86_64 kernel that boots through GRUB/Multiboot, switches into long mode, and hands most policy to a driver and service layer built around `.k64m` and `.k64s` binary artifacts. It ships its own filesystem format (K64XFS), an interactive shell, user-mode ELF execution, Ethernet networking, a package manager, and a Linux compatibility service (KLCS).

## Getting Started

<Steps>
  <Step title="Install build dependencies">
    On Fedora: `gcc`, `make`, `python3`, `qemu-system-x86_64`, `grub2-tools`, `xorriso`, `rsync`. A cross-compiler (`x86_64-elf-gcc`) is preferred but not required.
  </Step>
  <Step title="Build the ISO">
    ```bash
    make
    ```
    This produces `k64.iso` and `build/root.disk` — the bootable ISO and the persistent K64XFS disk image.
  </Step>
  <Step title="Boot in QEMU">
    ```bash
    make run
    ```
    QEMU starts with the ISO as the boot CD and `root.disk` as the persistent IDE disk. Serial output mirrors to your terminal.
  </Step>
  <Step title="Interact with the shell">
    After boot you land at:
    ```text
    [guest]@K64 ~/ >>>
    ```
    Try `help`, `ls /`, `servicectl list`, or `driverctl list` to explore the running system.
  </Step>
</Steps>

<Note>
  K64 currently targets BIOS/GRUB-style Multiboot on QEMU and legacy real hardware. Modern UEFI-only systems are not yet supported.
</Note>
